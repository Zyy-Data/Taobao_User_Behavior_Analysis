# Taobao User Behavior Funnel & Layering Analysis (淘宝用户行为漏斗与分层分析)

## 📌 项目背景
基于阿里云天池公开数据集（全量约 1 亿条行为记录，按用户抽样约 100 万条），旨在分析电商用户的转化路径、不同活跃度用户的购买差异，以及全天行为分布规律，为营销策略提供数据支持。

## 🛠️ 技术栈
- **数据处理**：Python (pandas 分块处理 3.5GB 数据)
- **逻辑校验**：SQL (CTE、窗口函数)
- **可视化**：Tableau

## 🚀 核心流程与发现
1. **数据清洗与漏斗建模**：处理异常时间戳后，构建“浏览 -> 加购/收藏 -> 购买”用户级漏斗。使用 SQL 与 pandas 双端计算并核对校验完全一致，整体转化率为 **60.81%**。
2. **用户分层分析**：按活跃天数分为低/中/高活跃层。高活跃用户占比达 **78.7%**，其购买转化率高达 **71.83%**（中活跃仅 52.08%），证明高频互动显著带动转化。
3. **时段行为洞察**：识别发现加购与购买的“双高峰”集中在 **晚上 21 点**。建议将核心营销动作（如优惠券推送）前置 1-2 小时，以承接流量。
